# Demo script (about 2 minutes)

Prep: `python3 -m server.app` with GEMINI_API_KEY set. Pre-scan the demo repos once so results are cached. Keep a screen recording as a backup.

0:00 Hook. "Every dead repo is a ghost. Commitmortem lets you talk to it."
0:10 Paste the story repo URL, click Scan. Narrate: commits become history, contributors become ancestors.
0:25 Ofrenda: point at the epitaph, a candle per milestone, a frame per contributor, marigolds sized by activity, and the unanswered prayers (open issues).
0:50 Seance: ask a specific question about a real commit. Show the AI-imitation label and the cited commits/issues. Then ask something it cannot know and show "I do not remember".
1:15 Haunting report: one or two hauntings with file and line.
1:30 Resurrect (on the repo prepared for it): click Resurrect, show the diff and the report. Say "sandbox only, nothing pushed".
1:50 Close. "Built on Gemma 4 and an open harness. Open source under MIT."

Pre-flight checklist: repo scanned, API key works, backup video recorded, README screenshots taken.
